# Gym Tracker 2.0

Локальный PWA-трекер тренировок. Все данные хранятся в браузере (localStorage).

## Как обновить сайт на GitHub
1. Открой свой репозиторий → **Add file → Upload files**.
2. Перетащи все файлы: `index.html`, `styles.css`, `app.js`, `seed.js`, `sw.js`, `manifest.json`, `README.md`.
3. Нажми **Commit changes**. Через 1–2 минуты GitHub Pages обновится.
4. На телефоне закрой приложение полностью и открой заново (иногда 2 раза), чтобы подтянулась новая версия.

Программа и история из бэкапа 09.11.2026 загружаются автоматически при первом запуске.
